# 回声 EchoMind 测试版 V18 · 更新说明

**版本**：v0.3.0-beta.18（测试版 V18）
**上一版**：V17（v0.3.0-beta.17）

---

## 一句话

这一版是**可用性清账**：把 V13 之后两天里踩出来的问题全部收口 ——
后端主文件瘦身近一半、两套标签合成一个入口、保存标签从 10 秒降到 0.5 秒、
导入从十几分钟压到 1 分钟内。

---

## 性能

| 场景 | V13 | V14 |
|---|---|---|
| 导入 6.5 万条音效 | 十几分钟 | 1 分钟内 |
| 保存标签 | 约 10 秒 | 0.5 秒 |
| 保存后左侧标签树刷新 | 7 秒 | 毫秒级 |
| 知识包写描述 | 卡在 64554 不动 | 一口气走完 |

### 怎么做到的

- 导入写库改批量事务（每 200 条落盘），DB 写操作走单线程避免抢锁
- 保存标签时清搜索缓存改为后台执行（原来是同步等检索器重建，实测 9.5 秒）
- 左侧标签树只拉 `/api/v1/tags`（0ms），不再连带等全库标签聚合（2.2 秒）

---

## 标签体系

**一个入口**：右键「编辑标签…」→ 选预设词或直接输入，保存时自动分流

```
预设词（环境/紧张/循环…）→ 系统标签，显示在列表那一行
自己输入的分类（片头/客户A…）→ 我的标签，显示在左侧栏
```

用户不需要知道底层是两套存储。

## 修复

- **一句话描述保存失败**（提示「保存失败，再点重试」）：路径规范化差异导致写入落空，改按文件 ID 兜底
- **系统标签 / 右键加标签保存失败**：拆模块时一个判断写漏了括号
- **重新读取目录扫到父目录**：库根目录改为按盘符求公共前缀，同级目录不会再被误扫补录
- **拖拽导出报错**（`handlePlaybackEnded is not defined`）：选区播放到末尾必现，已修
- **更新器静默挂起**：被占用时原来报「更新成功」其实没换，现在会真的完成替换或明确报错
- **知识包导入**：四级匹配、向量按文件 ID 去重、文本向量维度校验不再误判整包拒收
- **AI 生成音效**：落稳定目录（重启仍可试听）、历史支持重命名/定位/删除、响度标准化到 -16 LUFS

## 本版新增：长文本转语音

音色库面板右上角「长文本转语音」。粘贴整章文字，后台生成，
输出文件夹和文件名自己定。

```
1  文本      粘贴文字，右下角实时显示字数和预计时长
2  音色      选已克隆的音色，或留空用「声音设计」按描述构造
3  保存位置  默认 %APPDATA%\EchoMind\generated\日期\，可自选任意文件夹
4  开始生成  进度条按已落盘音频推进，可随时停止
```

实测：888 字生成 167 秒音频，耗时 100 秒；3648 字生成 629 秒（10.5 分钟），耗时 381 秒。
生成期间可以关掉窗口，任务在后台继续。

## 本版界面调整：两个标签页

打开「声音克隆」，标题下面是两个标签：

```
短音频克隆   选样音 → 克隆音色 → 输入台词念一句（原来那三步）
长音频克隆   粘贴整章文字 → 选音色 → 选保存目录 → 后台生成
```

**两个模式共用一个音色库。** 短音频里克隆出来的音色，切到长音频就能直接选，
下拉里显示的是你起的名字，不是 Breeze 内部的 id。
