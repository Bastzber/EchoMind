## 四、打包流程（重要，没有 npm）

这台机器上没装 npm，不能用 npm run build。手工流程：

第一步，打 app.asar：
```cmd
cd E:\音效库管理软件\EchoMind\EchoMind-main
.\.venv\Scripts\python.exe E:\AI音效管理器\build-asar.py
```

第二步，打更新包（会自己签名）：
```cmd
.\.venv\Scripts\python.exe scripts\build_update_package.py delta ^
  --target dist-v11-build\win-unpacked ^
  --base-manifest manifests\0.3.0-beta.12-baseline.manifest.json ^
  --version 0.3.0-beta.20-r02 ^
  --base-version 0.3.0-beta.20 ^
  --out dist-v11-build\update-beta20-r02.zip
```

更新包签名：

```
私钥    E:\AI音效管理器\update-signing-private.pem   （只在老板这台，绝不进仓库）
公钥    config/update-signing-public.pem              （硬编码进 lib/updater.js）
```

私钥丢了就再也签不出能装的包，务必提醒老板离线备份。

Electron 升级注意：手动下载 https://npmmirror.com/mirrors/electron/{版本}/electron-v{版本}-win32-x64.zip
解压覆盖 win-unpacked 里的文件（exe 改名 EchoMind.exe），同时同步到 node_modules/electron/dist。

## 七、今天踩过的坑（照着别再踩）

### 删了用户的 3 个音频文件

```
起因   测移动接口时直接拿用户库里的真实文件做实验
过程   shutil.move 成功 → UPDATE 报 no such column → 数据库没更新
       → 测试脚本 finally 里 rmtree 删了临时目录 → 文件没了
教训   1 测试绝不在用户真实数据上跑
       2 文件操作数据库失败必须回滚文件
       3 绝不自动删除用户文件
```

### 试听声音修了三遍才成

```
第一遍  停主界面的 audioPlayer        → 停错了对象
第二遍  遍历页面所有 audio 元素        → 抓不到（new Audio 不进 DOM）
第三遍  音色库自己持有播放器引用       → 才对
```

### 装包看不出装没装上

```
现象   每次装完界面都显示「已是最新版本 v0.3.0-beta.19」，无法判断
根因   那句话比对的是远程 update.json，跟本机装了什么无关
解决   加 build.buildStamp，检查更新时显示「构建 r33」
```

### 微信传大文件会截断

```
现象   11.7 MB 的 app.asar 传过去，放进 resources 后双击毫无反应
原因   传输中断，文件不完整，程序读不出 asar
解决   一律切 3 段 + 合并脚本，脚本先算 SHA256 再让用户动文件
```

### 增量包会误删用户数据

```
现象   V20-r01 第一次打出来的包，删除清单里有 49 个文件，
       包括 EchoMind-描述包.json、EchoMind-知识包.zip、整个 breeze/
原因   「基线有、本次包里没有」被当成「该删」
解决   build_update_package.py 加了删除白名单
```
