# 音效库分类方案（v1）

> 目标：**一个音频物理只存一份**，分类信息全部用标签表达；目录只负责"来源"，
> 不再用多层目录表达"用途"。这样库不会越用越臃肿，同一个声音也能被多个场景复用。

## 一、三个维度

| 维度 | 存放方式 | 是否互斥 | 例子 |
|---|---|---|---|
| **来源** | 目录（一层） | 每个文件只属于一个 | CJ音效库、z秋拾、大羽包、自己录制 |
| **类型** | 标签（scene 层） | **互斥，只能一个** | 环境、拟音、配乐、人声、UI、武器、动物 |
| **场景/用途** | 标签（attr 层） | 多值 | 紧张追逐、情节搭设、回忆梦境、欢快、恐怖、转场 |
| **特性** | 标签（attr 层） | 多值 | 循环、短尾、单发、长音、金属、机械、有混响 |

标签命名规范（重要）：**短、纯用途，不带序号和括号**

| 不要 | 要 |
|---|---|
| `7-各种情节搭设用` | `情节搭设` |
| `01 【音频】379个和交通工具有关的特效音频素材` | `交通` |
| `4-短配乐` | `配乐` |

## 二、目录怎么摆

推荐（**新素材**按这个放，老素材不用急着重排）：

```
D:\音效库\
  01-CJ音效库\      ← 来源，可以继续保留原来的子目录
  02-z秋拾\         ← 同上
  03-大羽包\
  04-自己录制\
```

关键：**别再用目录表达用途**。想按"紧张追逐"找，用标签筛选。

理由：
- 一个声音往往同时适合 2~5 个用途，目录只能表达一个 → 只能靠复制 → 空间翻倍
- 标签多值是免费的，改起来也不动磁盘

## 三、迁移步骤（工具已具备 / 待补）

| 步骤 | 工具 | 状态 |
|---|---|---|
| 1. 物理去重：每组保留一份，副本目录名转成标签 | 重复检测 →「保留选中的，其余分类转成标签后删源文件」 | ✅ 已有 |
| 2. 批量：目录名 → 标签（一次性把现有目录结构转成标签） | 待做（脚本 / 设置里的按钮） | ❌ |
| 3. 标签清理：批量改名、合并同义、删空标签 | 待做（标签面板批量操作） | ❌ |
| 4. 新素材导入时自动按目录名生成标签 | 待做（复用第 2 步逻辑） | ❌ |
| 5. 损坏文件容错转码（救回可解码的前段） | 待做（ffmpeg/PyAV 容错解码） | ❌ |

## 四、为什么不建议"把目录彻底拍平"

1. 剪辑工程里引用的路径会断（工程引用的是磁盘路径）
2. 其他软件（资源管理器、达芬奇、PR）按目录找素材，拍平后更难找
3. 拍平本身可逆性差

**结论：物理目录保持现状（或只按来源整理一层），分类靠标签。**
需要"按类型浏览"时，用左侧标签树，而不是文件夹树。
