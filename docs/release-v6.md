# 测试版 V6 发布说明

- 版本号：`0.3.0-beta.6`
- 安装包：`EchoMind测试版V6.zip`（3.33 GB）
- 日期：2026-10-24

## 这一版的重点

### 1. 标签双层（场景 / 属性）

- 左侧标签面板分成「场景」和「属性」两组
- 场景互斥（一个音效只能有一个），属性可多选
- 右键标签：设为场景 / 设为属性 / 删除
- 右键音效「设置标签…」：场景单选 + 属性多选，支持多选批量
- 点标签按后端过滤，搜索框支持 `tag:标签名`

### 2. 中文语义搜索

安装包内置 `bge-small-zh` 模型（92 MB），**离线可用**。

| 查询 | 引擎 | 耗时 |
|---|---|---|
| 玻璃 | FTS 关键词 | 0.06s |
| 爆炸 | FTS 关键词 | 0.04s |
| 像玻璃被击碎那种清脆的声音 | BGE 语义 | 0.36s |
| 沉重的脚步声踩在木地板上 | BGE 语义 | 0.1s |

首次启动后的**第一次**搜索会慢一些（约 8 秒，在建检索快照），之后都在 0.1 秒内。

### 3. 拟音工坊（环境音）

- 五类环境音：风与气流 / 雨天 / 林间鸟鸣 / 海边浪潮 / 篝火燃烧
- 四音轨常驻播放，拖动只改音量，**没有断层**
- 触控板四象限：远近 × 强弱
- 历史录音可单独试听 / 保存到库 / 复制路径
- 支持放入自己的素材：`%APPDATA%\EchoMind\ambience\<类型>\`

## 已知问题

- 林间鸟鸣在某些机器上可能没有声音（音频已确认有内容，播放链路待查）
- 标签体系数据为空，需要手动创建场景/属性标签

## 安装

1. 解压 `EchoMind测试版V6.zip`
2. 双击 `EchoMind.exe`
3. 首次启动会加载模型（约 30 秒），之后正常

> 安装包内**不包含任何音效素材**，请使用自己的音效库。
