# EchoMind 测试版 V6 安装指南

> 版本号：`0.3.0-beta.6`
> 安装包：`EchoMind测试版V6.zip`（3.33 GB）
> 适用系统：Windows 10 / 11（64 位）

---

## 一、安装包在哪

```
E:\音效库管理软件\EchoMind\EchoMind-main\dist-electron-v5\EchoMind测试版V6.zip
```

这是个**免安装压缩包**，解压即用，不需要安装程序、不需要管理员权限。

---

## 二、电脑要求

| 项目 | 最低 | 建议 |
|---|---|---|
| 系统 | Windows 10 x64 | Windows 11 x64 |
| 内存 | 8 GB | 16 GB 以上 |
| 可用磁盘 | 10 GB | 40 GB 以上（音效库另算） |
| 显卡 | 无要求 | 有 NVIDIA 显卡更快（自动启用 CUDA） |

> 程序自带 Python 运行时和全部依赖，**不需要装 Python、不需要联网**。

---

## 三、安装步骤

### 1. 解压

右键 `EchoMind测试版V6.zip` → 解压到你想放的目录，例如：

```
D:\软件\EchoMind
```

> ⚠️ 建议放在**非系统盘**，不要放在 C 盘根目录或带中文空格的深层路径下。
> 解压后应看到 `EchoMind.exe` 和 `resources` 文件夹。

### 2. 第一次启动

双击 `EchoMind.exe`。

首次启动会发生这些事：

- 解压模型文件（约 30 秒）
- 后台加载 CLAP 音频模型
- 后台建中文检索索引

窗口可能短暂白屏或未响应，**属于正常现象**，等 30~60 秒即可。

### 3. 建桌面快捷方式（可选）

右键 `EchoMind.exe` → 发送到 → 桌面快捷方式。

---

## 四、首次使用

### 1. 导入音效库

点顶部 **导入** → **导入文件夹**，选择你的音效目录。

- 支持 `.wav` `.mp3` `.flac` `.ogg` 等常见格式
- 导入后会**自动**提取波形、生成 AI 一句话描述、建立索引
- 5 万条素材大约需要 2~4 小时（后台跑，可以正常使用）

右下角 / 顶部状态栏可以看到进度：

```
Audio 已索引 48648 · 待处理 0 · 失败 0
Text  已索引 48648 · 待处理 0 · 失败 0
```

### 2. 配置大模型（可选，但推荐）

设置 → AI 设置 → 自定义 API

```
API 地址：https://api.deepseek.com/v1
API Key：你的 key
模型名称：deepseek-flash
```

点「测试连接」确认可用，再「保存配置」。

**不配置也能用**：搜索、标签、拟音工坊都不依赖大模型，只是描述质量会差一些。

---

## 五、主要功能怎么用

### 搜索

搜索框在主列表最上方，**按回车**才搜：

- 短词（如「玻璃」）：0.05 秒
- 长句（如「像玻璃被击碎那种清脆的声音」）：0.3 秒，自动走语义

### 标签

左侧标签面板分「场景 / 属性」两组：

- 右键音效 →「设置标签…」→ 场景单选、属性多选
- 右键标签 → 设为场景 / 设为属性 / 删除

### 拟音工坊

顶部「拟音工坊」→ 选环境（风 / 雨 / 鸟鸣 / 海浪 / 篝火）→ **按住左键**拖动触控板：

```
远处·细雨          远处·暴雨
        ● 拖动点
近处·细雨          近处·暴雨
```

- 左右 = 远近，上下 = 强度
- 点「开始录制」→ 拖动 → 「完成录制」
- 每条录音可单独试听 / 保存到库 / 复制路径

### 文件夹管理

- 右键文件夹 →「删除文件夹…」，可选只删库内记录或连源文件一起删
- 右键音效 →「添加到文件夹…」→ 常用，之后点左侧「常用」查看

## 六、数据存在哪

| 内容 | 路径 |
|---|---|
| 数据库 | `%APPDATA%\EchoMind\db\soundmind.db` |
| 向量索引 | `%APPDATA%\EchoMind\chroma_projects\default\` |
| 日志 | `%APPDATA%\EchoMind\logs\` |
| 自定义环境音素材 | `%APPDATA%\EchoMind\ambience\` |

**备份**：直接复制整个 `%APPDATA%\EchoMind` 文件夹。

**清空重来**：删除该文件夹，下次启动会重建（音效文件本身不受影响）。

---

## 七、卸载

1. 关闭软件（任务管理器确认没有 `EchoMind.exe` 和 `soundbot-backend.exe`）
2. 删除解压出来的程序目录
3. 需要彻底清理时，再删除 `%APPDATA%\EchoMind`

---

## 八、常见问题

### 启动后白屏 / 黑屏

先等 60 秒（模型在加载）。若一直黑屏，在窗口里按 `Ctrl+R` 刷新界面。

### 提示端口被占用 / 后端未就绪

可能是上次进程没退干净：

1. 任务管理器结束所有 `EchoMind.exe`、`soundbot-backend.exe`
2. 重新启动

### 杀毒软件报毒

免安装包用了 PyInstaller 打包，常被误报。加入白名单即可。

### 第一次搜索很慢（约 8 秒）

后台在建检索快照，之后都在 0.1 秒内，属正常。

### 导入后没有描述

检查 AI 设置里的 API Key 是否可用；也可以先在设置里「测试连接」。
