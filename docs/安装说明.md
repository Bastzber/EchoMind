# 回声 EchoMind 安装说明

版本：**0.3.0-beta.11（r8）**　构建日期：2026-10-26

---

## 一、系统要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 1809 及以上 / Windows 11（64 位） |
| 内存 | 建议 8 GB 以上（索引 + 语义搜索时占用较高） |
| 磁盘 | 程序约 3.4 GB；音效库另算 |
| 显卡 | 无强制要求（本地 AI 模型可选） |

## 二、安装（绿色版，解压即用）

1. 把 `EchoMind测试版V11.zip` 解压到**非中文路径也可，但建议固定位置**，例如 `D:\EchoMind`
2. 进入解压后的 `win-unpacked` 目录，双击 **EchoMind.exe**
3. 首次启动会自动在后台启动本地服务（约 10–40 秒），窗口右下角出现「索引状态」即为就绪
4. 不需要单独安装 Python、Node.js、数据库——全部已打包在内

> 注意：不要只把 `EchoMind.exe` 单独复制走，它依赖同目录的 `resources` 文件夹。

## 三、第一次使用

1. 点顶部 **文件 → 导入文件夹**，选择你的音效库根目录
2. 等待索引完成（索引状态会显示「已索引 / 待处理」）
3. 可选：**导入描述包** 一次套用几万条描述和标签（见下方「配套数据包」）

## 四、数据存放位置（升级不丢）

| 内容 | 路径 |
|---|---|
| 数据库 | `%APPDATA%\EchoMind\db\soundmind.db` |
| 向量库 | `%APPDATA%\EchoMind\chroma_projects\default` |
| 皮肤 | `%APPDATA%\EchoMind\skins` |
| 音色档案 | `%APPDATA%\EchoMind\voice_profiles` |
| 更新备份 | `%APPDATA%\EchoMind\update-backup` |
| 报告 / 导出 | `%APPDATA%\EchoMind\reports` |

**升级只替换程序目录，以上目录不会被改动。**

## 五、配套数据包（可选，放在解压目录根下即可）

| 文件 | 内容 | 条目 | 大小 |
|---|---|---|---|
| `EchoMind-描述包.json` | 一句话描述 + 系统标签，按「相对库路径」匹配 | 64,781 | 19.0 MB |
| `EchoMind-标签包.json` | 系统标签 + 用户标签 + 词表统计 | 64,983 | 16.5 MB |

用法：顶部 **导入描述包** → 选择对应 json → 先「预览匹配」再「应用」。
匹配按相对路径（大小写不敏感），换盘、换机器都能对上；匹配不上的条目会列出来。

## 六、更新方式

| 场景 | 用哪个包 | 说明 |
|---|---|---|
| 从 r7 升级 | `update-0.3.0-beta.11-r8.zip`（61.9 MB） | 只含改动的程序文件，解压覆盖到程序目录 |
| 全新安装 / 跨大版本 | `EchoMind测试版V11.zip`（3.39 GB） | 完整程序 |

增量包更新步骤：

1. 完全退出 EchoMind（托盘图标右键 → 退出）
2. 把增量包解压，内容**覆盖**到 `win-unpacked` 目录（保留目录结构）
3. 重新启动 EchoMind

也可以在应用内：**设置 → 关于与更新 → 选择本地更新包**，由程序自己校验并应用（失败会回滚）。

## 七、卸载

1. 退出程序
2. 删除程序目录
3. 如需彻底清除数据，再删除 `%APPDATA%\EchoMind`（**会丢失标签、描述、索引**）

## 八、常见问题

| 现象 | 处理 |
|---|---|
| 启动后一直「服务启动中」 | 检查 8000 端口是否被占用；关闭其他占用进程后重启 |
| 杀毒软件报毒 | 未签名程序的常见误报，添加信任即可 |
| 导入很慢 | 首次导入要计算指纹 + 生成波形/向量，7 万条约 1–2 小时 |
| 搜索没结果 | 确认索引状态为「已索引」；阈值滑块不要拉得太严 |
| 中文乱码 | 系统区域设置需支持中文（非 Unicode 程序语言设为中文） |

## 九、目录结构

```
win-unpacked/
├─ EchoMind.exe              主程序
├─ resources/
│  ├─ app.asar               界面与逻辑
│  └─ backend/               本地服务（Python 打包）
├─ EchoMind-描述包.json       配套数据包（可选）
├─ EchoMind-标签包.json
└─ 安装说明.md / 更新统计.md
```
