## 一、本项目不含音频素材

| 交付物 | 是否包含音频 |
|---|---|
| GitHub 仓库 | **0 个音频文件** |
| 安装包 `EchoMind测试版V5.zip`（3.27 GB） | **0 个音频文件**（仅程序、模型、UI） |
| 描述包 `EchoMind-描述包.json` | **0 个音频文件**（纯文本描述） |

软件提供的是**管理、索引、检索**能力。音效音频始终保存在用户自己的磁盘上，
软件只在本地建立索引，不上传、不外传。

## 二、音效素材的版权归属

用户导入的音效素材，其版权归**各自的权利人**所有，与本项目的 GPL-3.0 许可证无关。

GPL-3.0 只覆盖本项目的**源代码**。它不会、也不能授予你对第三方音效素材的任何权利。

## 三、关于二次分发（重要）

如果你打算把音效文件与软件一起打包分发（例如「软件 + 音效库」整合包、网盘分享、发给客户），请注意：

1. **商业音效库的授权通常禁止再分发**，只允许购买者本人在其项目中使用。
2. **来源不明的素材**（网上下载、论坛分享、别人给的）不能默认视为可自由分发。
3. **免责声明不能替代授权。** 写一段「仅供学习交流」并不改变侵权认定。
4. 真正安全的做法只有三种：
   - 只分发软件，用户自己导入自己的素材；
   - 只附带你有权分发的素材（自己录制、自己合成，或 CC0 / 明确允许再分发的素材）；
   - 附带素材时逐一声明来源与许可证，并保留原授权文件。

## 五、English summary

This repository and its installer contain **zero audio files**. The software only manages and indexes a user's own
library on their own disk; nothing is uploaded. Copyright in any sound effect belongs to its respective owner and
is unrelated to this project's GPL-3.0 license, which covers **source code only**.

**Do not redistribute third-party sound libraries.** Commercial SFX licenses generally prohibit redistribution, and
a disclaimer does not grant you a license. If you ship audio with the app, you must hold the redistribution rights
and document the source and license of every asset.
