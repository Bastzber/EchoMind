## 五、已知坑（这几条今晚都踩过）

1. **构建命令里的路径别写错**：今晚有一次写成 `E:\AI音效库管理软件\...`（多了个 AI），构建没跑但没报错，白等 8 分钟。
2. **验证参数要和界面一致**：AI 搜索界面发 `top_k: 50000`，我用 `top_k: 3` 测过就以为好了，实际 SQLite 999 参数上限直接抛错被吞。
3. **重新打包/部署前先确认构建真的跑了**：看产物时间戳（exe / asar）。
4. **SQLite 参数上限 999**：批量子句要按 ≤500 分批。
5. **`canonical_path` 斜杠方向**：库里存 `f:\`，`canonicalize_path` 产出 `f:/`，按路径删会全部匹配失败，改用 uuid。
6. **FK 级联很慢**：开着 `foreign_keys` 删 files，100 个文件 29.5 秒；批量删要先关 FK 再显式删子表。
7. **中文路径下 `tools.read` 偶尔报 not found**（环境问题）：改用 python 脚本或 forward-slash 路径兜底。
8. **索引器每次构造都要重开 Chroma 集合**（9.8s / 14.6s）：循环里绝不能反复调 `_get_active_*_indexer()`。
