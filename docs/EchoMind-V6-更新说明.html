EchoMind 测试版 V6 更新说明

> 版本号：0.3.0-beta.6

> 适用：Windows x64

> 安装包：EchoMind测试版V6.zip（3.33 GB）

> 更新日期：2026-10-24

本次更新一共四块大功能，全部可以在界面上直接使用。

---

一、标签体系升级为「场景 + 属性」双层

以前的问题

所有标签平铺在一起，「枪械」「短促」「金属」混在一个列表里，既不能区分层级，也无法约束。

现在怎么用

左侧标签面板分成两组：

我的标签
  场景            ← 一个音效只能有一个
    🎬 枪械  1204
    🎬 环境   803
  属性            ← 可以有很多个
    🏷 短促  3021
    🏷 金属   890

**给音效打标签**

1. 在主列表里右键任意音效（可先多选）

2. 选「设置标签…」

3. 弹窗分两段：场景（单选）、属性（多选）

4. 点「应用」

**管理标签**

  • 右键标签 → 「设为场景标签」/「设为属性标签」/「删除标签」
  • 新建标签时会先问一句：确定 = 场景，取消 = 属性

    • **按标签筛选**

  • 直接点左侧标签 → 主列表显示该标签下所有音效
  • 或在搜索框输入 `tag:动物` 回车

    • 约束规则

    规则行为
    一个音效最多一个场景选第二个场景会被后端拒绝（400）
    属性不限数量想加多少加多少

    二、中文语义搜索（离线）

    以前的问题

    输入一句完整的话（「像玻璃被击碎那种清脆的声音」），只能匹配文件名或描述里的字面词，搜不到语义相近的素材。

    现在怎么用

    搜索框仍然在列表最上方，**按回车才搜**：

  • **短词**（≤4 字）：走关键词索引，回车后 **0.05 秒**出结果
  • **长句**（≥5 字）：自动走语义模型，**0.3 秒**出结果

    • 实测对比：

    输入结果
    `玻璃`0.06s，关键词命中
    `像玻璃被击碎那种清脆的声音`0.36s，首条是「打碎玻璃声.wav」，相似度 0.861
    `沉重的脚步声踩在木地板上`0.1s，命中「鞋声」「木地板上走」

    **完全离线**：模型（92 MB）已内置在安装包里，不需要联网、不需要 API Key。

    注意

    程序启动后的**第一次**搜索会慢约 8 秒（在后台建检索快照），之后都在 0.1 秒内。这不是卡死。

    三、拟音工坊（环境音合成）

    顶部新增「拟音工坊」按钮，五个环境类别：

    类别四层内容
    风与气流柔风底声 / 阵风细节 / 强风气流 / 点缀音
    雨天雨声底噪 / 雨点细节 / 雷声
    林间鸟鸣林间底噪 / 鸟鸣 / 虫声
    海边浪潮海浪底声 / 浪花细节 / 海风
    篝火燃烧火焰底声 / 噼啪细节

    怎么用

    1. 选一个环境

    2. **按住左键**在触控板上拖动（松手后光标移动不再影响声音）

    3. 四个角对应四种状态，例如雨天：

    远处 · 细雨          远处 · 暴雨
        ● 拖动点
近处 · 细雨          近处 · 暴雨
  • **左右** = 远近（越右越近，雨滴越清脆）
  • **上下** = 强度（越下越大）

    • 4. 点「● 开始录制」→ 拖动 → 「■ 完成录制」

    5. 历史录音里每条都有：**试听 / 保存 / 复制路径**

    换成自己的素材

    把 wav/mp3 放进：

    %APPDATA%\EchoMind\ambience\rain\
%APPDATA%\EchoMind\ambience\wind\
%APPDATA%\EchoMind\ambience\sea\
%APPDATA%\EchoMind\ambience\fire\

    每个文件夹放 1~4 个文件（按文件名顺序对应四层）。程序会自动做循环点交叉淡化和响度归一，不需要自己处理。

    ---

    四、文件夹与列表操作

    右键文件夹 → 删除

    弹窗会明确列出将删除什么：

    库内文件      847 条
一句话描述    847 条
标签          0 条
源文件占用    2.81 GB

    然后二选一：

  • **仅从软件中移除（保留源文件）** ← 默认
  • **删除源文件并从软件移除** ← 需勾选确认，且走回收站

    • 右键音效 → 添加到文件夹

    选「添加到文件夹…」→ 点「常用」→ 之后点左侧「常用」就能看到这些音效。

    列表 / 卡片视图

    搜索栏右侧两个图标可切换：

  • ☰ 列表（表格，默认）
  • ▦ 卡片（封面 + 名称 + 描述 + 标签 + 小波形）

    • 选择会记住，下次打开保持。

    五、其他改进

    项目变化
    搜索框位置从右上角移到主列表顶部，整行宽度
    搜索触发改为**按回车**，不再边打字边出结果
    顶部按钮「创造音效」「拟音工坊」换成毛玻璃科技风，图标加大
    设置菜单修复被导航栏裁切打不开的问题
    导航栏窄窗口不再挤爆布局
    用户文件夹计数现在包含手动加入的音效
