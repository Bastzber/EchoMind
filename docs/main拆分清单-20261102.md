## 四、已建立的搬迁模式

1. **新模块只 import core**：`from core.database import get_db_manager` 这种最干净，优先。
2. **要调主模块私有函数时用 `api/routers/_deps.py`**：
   ```python
   from api.routers import _deps as _d
   def _repair_index_task(*a, **k):
       return _d.call("_repair_index_task", *a, **k)
   ```
   `_deps` 从 `sys.modules` 取已加载的主模块，**不会触发重复导入**（`import main` 在打包后会重新执行入口，是灾难）。
3. **主模块自己定义的 pydantic 模型**：搬模块时一起搬过去，别用代理（要参与类型解析）。
4. **跨模块的全局状态**（如 `_rescan_state`）：搬的时候把状态也搬走，主模块反向 import 那个模块取状态。
