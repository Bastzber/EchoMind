## 三、本轮做完的功能

### 语音（重点）
- **本地 Breeze TTS 2（GGUF / Vulkan）已装好并跑通**
  - 程序：`E:\AI音效管理器\breeze\breeze-tts-2-v0.1.3-windows-x64-vulkan\breeze-server.exe`
  - 权重：`C:\Users\cj\breeze-weights\breeze-tts-2-q8_0.gguf`（3.32 GB）

- 后端语音层 `backend/core/tts.py`：优先级 **Breeze 本地 → 豆包云端 → 报错**

  - `POST /api/v1/assistant/speak {text}`（助理播报）
  - `POST /api/v1/voice/clone {path,name,provider,ref_text}`（provider=breeze 只登记参考音频+文稿）

  - `GET/PATCH/DELETE /api/v1/voice/profiles[/{id}]`
  - `POST /api/v1/files/copy {source,destination,overwrite}`
  - `GET /api/v1/tts/status`
- 前端「声音克隆」：引擎下拉（本地/云端）、样音文稿、克隆、试听、保存为 WAV、音色库管理（试听原声/试听合成/改名/改文稿/删除）
- 输出格式可选：单声道/双声道 × 24k/48k（双声道是左右相同的双单声道，48k 是上采样）

## 四、Mesh Avatar Studio 验证结论（2026-10-28 晚）

- 仓库：https://github.com/shinshin86/mesh-avatar-studio ★1342 MIT TypeScript
- 作用：一张插画 → 分层网格 2D 虚拟形象（眨眼/说话嘴型/转头/呼吸/头发摆动）
- 运行时：`mesh-avatar` ESM + `<mesh-avatar>` 自定义元素（`mesh-avatar-element`），WebGL，无需框架
- **验证结果（都通过）**
  - Chromium：元素注册 ✔ 加载 `miko.mavatar`（2.1 MB）✔ WebGL ✔
  - 表情切换：与基准帧差 39,469 像素（区域正好是头部）
  - 说话音量 0.9：差 47,946 像素（嘴型张开）
  - **Electron 里同样通过**：`{gl:true, hasAvatar:true, defined:true}`，截图确认微笑+张嘴
- 测试文件（可复用）：
  - `E:\AI音效管理器\mesh-avatar-test\`（index.html + miko.mavatar + standalone.js + serve.js，8899 端口）
  - `mesh-avatar-test\electron\main.js`（Electron 外壳）
- 接入要点：
  - 页面必须走 http(s) 或自定义协议，`file://` 下 ES module 会被 CORS 拦
  - 驱动 API：`avatar.setSpeaking(true)` / `setVoiceLevel(0..1)` / `setExpression('smile')` / `setEmotion('happy')`
  - 需要一张插画（正面/头肩/透明背景 PNG）→ Studio 生成 `.mavatar` → 放进 resources 由渲染层加载
