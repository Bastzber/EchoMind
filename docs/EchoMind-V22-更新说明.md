# EchoMind 回声 V22 更新说明（0.3.0-beta.22）

发布日期：2026-11-25 · Windows x64

## 一句话

声音克隆从"要另开一个软件"变成**装完就能用**；主界面按确认过的原型重排。

## 声音克隆（重点）

- **内置 OmniVoice 引擎**：k2-fsa OmniVoice（Qwen3 底座 + Higgs 音频分词器），不再依赖 VoiceStudio 应用。首次选该引擎会下约 3.1 GB 权重到 `%APPDATA%\EchoMind\models\omnivoice`，之后离线可用；推理跑在独立子进程，崩了不连累主程序
- **引擎下拉框真正生效**：以前说话只看音色档案自带的引擎，换下拉框没反应（截图里引擎选 VoiceStudio、产物却是 `breeze-*.wav` 就是这个 bug）
- **"克隆了但都是一个声音"修好了**：Breeze / OmniVoice 缺"样音文稿"时不再静默退回默认声音，改成明确报错 + 列表里黄点一键补文稿
- 克隆结果**可以导出到任意目录**、**可以保存到音效库**（原来被路径校验拒绝）
- 面板重排成"左音色库 + 右工作区"：每行音色可试听样音，主次按钮分网格，窄窗不再竖排
- 生成完**不再自动播放**；试听按钮变成播放/暂停切换

## 主界面

- 工具条收进「工具 ▾」抽屉：默认收起，Ctrl+T 展开，按 日常 / 修数据 / AI 分三行
- 顶部六个入口统一成带边框的中性按钮、整体靠左排，去掉紫/青/粉渐变与发光
- 左栏换成「库 / 整理」分组导航；文件夹树、标签、历史按需展开；「最近使用」把播放历史直接列进主列表
- 列表补「标签」列、恢复显示一句话描述，行高更紧凑
- 窗口无边框 + 四角 14px 圆角（Win10 也生效），顶栏自绘最小化/最大化/关闭；启动页重做，品牌标记换成应用图标

## 修掉的小毛病

- 模型胶囊只有问号能点（顶栏拖拽区吞点击）→ 现在整块可点，弹窗里能看到阈值当前效果并可恢复默认 0.15
- 损坏文件面板的 ✕ 点不动 → 捕获阶段委托，点遮罩也能关
- 历史条目点不动（找不到就按 id 回查，再不行按路径播）
- 点「收藏」显示全部音效 → 直接调收藏视图

## 已知限制

- 内置 OmniVoice 权重需要联网下载一次；公司网络需代理，或手动放置权重目录
- 长音频面板已删除（短音频本身能念 4 分半）
- 旧版 VoiceStudio 档案仍可用内置引擎重新合成，但不再支持"打开 VoiceStudio 应用"这条路

## 升级方式

- 全新安装：`EchoMind测试版V22.zip`（约 7 GB，解压即用）
- 增量升级：`update-beta22-r01.zip`（约 72 MB，Ed25519 验签，自动备份到 `%APPDATA%\EchoMind\update-backup`）

详细安装步骤见 `docs/EchoMind-V22-安装指南.md`。
