# 回声 EchoMind 测试版 V11 · 安装指南

**版本**：v0.3.0-beta.11（测试版 V11）
**平台**：Windows 10 / 11（64 位）
**包大小**：3.39 GB（解压后约 5.2 GB）

---

## 一、系统要求

| 项目 | 最低 | 建议 |
|---|---|---|
| 系统 | Windows 10 64 位 | Windows 11 |
| 内存 | 8 GB | 16 GB 以上 |
| 显卡 | 支持 CUDA 的 N 卡（可选） | 6 GB 显存以上 |
| 磁盘 | 程序 6 GB + 你的音效库空间 | 音效库建议放机械硬盘 |

> 没有 N 卡也能用，会自动走 CPU，只是语义搜索和索引会慢一些。

---

## 二、安装（免安装，解压即用）

1. 下载 EchoMind测试版V11.zip（3.39 GB）
2. 解压到**任意目录**，例如 D:\EchoMind（路径可以带中文，但别放在 C 盘根目录）
3. 进入解压出的 win-unpacked 文件夹，双击 **EchoMind.exe**

启动时如果出现蓝色窗口提示「Windows 已保护你的电脑」：

```
点「更多信息」→ 点「仍要运行」
```

这是因为程序没有购买数字签名（测试版），不是病毒。

---

## 三、首次启动（重要）

**第一次启动需要等 1~2 分钟**，界面可能白屏或转圈，这是正常的：

```
正在加载 CLAP 音频模型（约 500 MB）和 BGE 文本模型
模型加载完成后，界面会自动进入主界面
```

如果超过 3 分钟还没进去：

1. 看任务管理器里有没有 soundbot-backend.exe 在跑（有就是在加载）
2. 关掉程序重新开一次（第二次会快很多）
3. 还是不行就检查杀毒软件是否拦截了 soundbot-backend.exe

---

## 四、导入你的音效库

1. 点左上角选库目录，或把文件夹拖进窗口
2. 首次导入会扫描并建立索引：

| 文件数 | 首次耗时（参考） |
|---|---|
| 1 万 | 约 20 分钟 |
| 5 万 | 约 1.5 小时 |
| 7 万 | 约 2 小时 |

3. 索引在后台跑，界面可以正常用；状态栏能看到进度

---

## 五、数据存在哪

```
程序：你解压的那个文件夹（删掉 = 卸载）
数据：C:\Users\你的用户名\AppData\Roaming\EchoMind
  ├─ db\soundmind.db        ← 数据库（标签/描述/索引状态）
  ├─ chroma_projects\       ← 向量库
  └─ logs\                  ← 日志
```

**换电脑或重装**：把整个 EchoMind 数据文件夹拷过去，放到新电脑的同一位置即可。

**卸载**：删掉程序文件夹 + 删掉 %APPDATA%\EchoMind。

---

## 六、常见问题

**Q：启动失败 / 一直白屏？**

等 2 分钟；还不行就重启一次程序。V11 已把启动超时从 60 秒放宽到 240 秒。

**Q：播放没声音？**

先确认这个文件本身有声音（用系统播放器试）。本版本有 200 多个文件是源素材本身损坏的，会显示「损坏文件」。

**Q：索引一直显示「待处理」不动？**

索引任务断了。重启程序后会自动续跑，也可以点状态栏的「重建索引」。

**Q：能装到移动硬盘吗？**

可以。程序和音效库都能放移动硬盘，但索引速度会慢很多。

**Q：会联网吗？**

只有两个地方联网：检查更新、AI 描述/生成音效（需要你自己配 API Key）。其余全部本地。

---

## 七、反馈

遇到问题请带上：

1. 版本号（设置 → 关于）
2. %APPDATA%\EchoMind\logs\ 里最新的日志文件
