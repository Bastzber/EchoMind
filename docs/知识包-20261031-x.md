
## 系统标签说明与同义词合并（10-31 17:00）

### 系统标签怎么来的

不是独立功能，**跟着「批量生成一句话描述」一起产出**：一次 LLM 调用同时返回描述和 4~8 个标签，
写入 `files.tags`。UCS 关键词匹配只用于搜索文本，不写进 `files.tags`。

实测：64,920 个文件里 62,813 个有系统标签（96.8%），合并前共 3,990 个不同标签。

UI 已在设置页「批量生成一句话描述」下方加说明卡片，写明标签来源。

### 同义词合并

规则：去掉后缀（质感 / 声 / 音 / 声效 / 感）后同名的标签视为同义词，
保留组内出现次数最多的写法，其余并入。

```
合并前  3,990 个标签
合并组  129 组，消除 156 个标签
改写    10,463 个文件的 tags 字段
合并后  3,834 个标签
```

典型例子：

```
金属质感 <- 金属(2570) / 金属声(51) / 金属感(12)
电子质感 <- 电子(998) / 电子音(201) / 电子音效(3)
环境     <- 环境音效(218) / 环境音(198) / 环境声(163)
```

**备份**：`%APPDATA%\EchoMind\tag-backup-20261031-170741.json`（62,813 条），
需要回滚时按 file_uuid 把 tags 原样写回即可。

**注意**：这次只改了展示用的标签，没有把 10,463 个文件标记为「文本向量过期」——
否则要重算几小时。搜索仍按原向量工作，标签规范化只影响展示和筛选。
