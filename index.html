音频生成（豆包语音）

用于「创造音效」功能：输入文字描述即可生成音效。API Key 在火山引擎控制台 → 豆包语音 → API Key 管理获取（X-Api-Key）。

生成后的音效会保存到此目录并自动加入 AI 搜索索引

批量生成一句话描述

为库中音效批量生成 AI 一句话描述。描述写入后会同步进文本索引，之后搜索时描述也能被直接命中（无需每次调用 AI）。可断点续跑：中途停止后再次点击会继续处理剩余文件；完成后自动重建文本索引。

知识包（换电脑、分享给别人用）

一个 zip 里同时包含 一句话描述、标签、 音频向量 和 文本向量。别人把软件和知识包拿走，导入自己库里的音效后， 点「导入知识包」即可全部套用，不用再跑几小时索引。 后来只加了一批新音效？点「导出增量包」，选上次那个包当基线，只导出新增部分。

关闭窗口时

点击右上角 × 时的行为。选择"最小化到托盘"后，软件会缩到任务栏右下角继续运行，索引和搜索都不会中断。
