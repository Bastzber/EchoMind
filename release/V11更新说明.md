# 回声 EchoMind 测试版 V11 · 更新说明

**版本**：v0.3.0-beta.11
**发布日期**：2026-10-25
**上一版**：V10（0.3.0-beta.10）

---

## 这一版做了什么

一句话：**把几个来源的音效库，合并成一套统一的分类体系。**

| | 迁移前 | 迁移后 |
|---|---|---|
| 音效文件 | 分散在两个库、目录结构各不相同 | 统一到 F:\CJ音效库整合包V1 |
| 分类 | 几十个平级目录、名称不统一 | 14 个一级 + 88 个二级 |
| 同一音效 | 多个用途要复制多份 | **只存一份**，用途用标签表达 |
| 标注 | 大部分没有描述 | 70,448 条描述 + 3,994 个标签 |

---

## 一、新的分类体系

### 14 个一级分类

```
交通工具    人声与身体   动物与昆虫   撞击与材质
机械与工业  武器与爆破   环境氛围     生活与器具
电子与界面  科幻与奇幻   脚步与服装   自然与天气
转场与设计  音乐与乐器
```

### 规则

- 目录最多 3 层：`一级\二级\文件`
- 形态词（连续 / 单次 / 循环 / 长尾 / 短尾）**不进目录名**，只做标签
- 一个音效只存一份，多个用途用标签区分

---

## 二、标签体系

每条音效 6 个标签，来自 6 个维度（沿用行业通用的做法）：

| 维度 | 取值举例 |
|---|---|
| 形态 | 连续 / 单次 / 循环 / 长尾 / 短尾 / 掠过 / 上升 / 下沉 |
| 频段 | 低频 / 中频 / 高频 |
| 质感 | 电子 / 金属 / 木质 / 玻璃 / 空气 / 失真 |
| 强度 | 强烈 / 中等 / 柔和 / 轻微 |
| 空间 | 干声 / 混响 / 远场 / 近场 |
| 语言 | 中文 / 英语 / 男声 / 女声 / 对白 |

高频受控词约 38 个，覆盖大部分场景；其余是具体名词（钢琴、空灵、梦幻）。

## 三、新增功能

### 1. 音频转码

右键任意音效 →「转码为 WAV / MP3…」

- 剪辑软件不认的格式（OGG / OPUS / APE / WMA / CAF）一键转成 WAV 或 MP3
- 可选输出目录（默认在原文件夹下建 `_转码` 子目录）
- **损坏文件容错解码**：能救回坏点之前的音频

### 2. 标签批量管理

左侧「我的标签」标题右侧的齿轮：

- 勾选多个标签 → 一次合并成一个 / 一次删除
- 一键套用 21 个预设标签（类型 7 + 场景 7 + 特性 7）

### 3. 路径修复

重复检测窗口工具栏 →「修复路径」

在磁盘上改了文件夹名、或把文件夹移了位置之后，按「同名同大小」把库里的路径修正回来，不用重新导入。

### 4. 重复检测增强

- 「整组删除（含保留的那份）」：适合整组都是静音/无效文件的情况
- 「这一组要保留在多个分类（忽略）」：诚实的跨分类音效不再反复提示
- 「保留选中的，其余分类转成标签后删源文件」：删副本前先把目录名记成标签

### 5. 界面细节（本版新增）

- **主列表标签全部展示**：一个音效有几个标签就显示几个，不再折叠成 `+3`；标签排在文件名下面一行，自动换行
- **侧边栏标签收拢**：只显示最常用的 14 个，点「查看全部 N 个标签…」才展开，避免几千个标签刷屏
- **导入描述包入口前置**：顶部工具栏新增紫色「导入描述包」按钮，导入下拉菜单里也有入口（设置页原位置保留）

### 6. 描述包未匹配清单导出

导入描述包时，把没匹配上的条目导出成 CSV，方便回源包补。

## 四、修复的问题

| 问题 | 说明 |
|---|---|
| 启动超时 | 模型预热需要 100 秒左右，原来 60 秒超时导致「启动失败」。现在放宽到 240 秒 |
| 时长显示 0 | 库里 28,552 条音效的 duration 是 0（其实是有效的），已全部回填 |
| 标签不同步 | 改名或合并标签后，列表和标签树显示不一致 |
| 哈希补算只跑一次 | 新导入的文件没算 sha256，导致重复检测漏检 |

## 五、升级注意

**从 V10 升级**：

1. 直接解压新包，覆盖原来的程序目录即可
2. 数据（%APPDATA%\EchoMind）会自动沿用，标签和描述不会丢
3. 如果你的库目录变了，需要在设置里重新指定，然后点「修复路径」

**首次使用建议顺序**：

```
1. 导入音效库（或指定现有库目录）
2. 等索引跑完（状态栏 Audio / Text 待处理都归 0）
3. 打开重复检测，按组处理重复
4. 用标签管理把标签整理成那 20~40 个高频词
```
