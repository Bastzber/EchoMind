# 音效库分类标准（v5 · 定稿）

> 依据：大羽软件 34,190 条音效的实际数据（标签互斥性违反率 0.01%~0.82%、标签与目录名重合仅 14.5%、
> 14 个一级分类覆盖均衡）。**标签体系照抄，目录压到 3 层。**

## 一、目录结构（最多 3 层）

```
D:\音效库\<一级分类>\<二级分类>\文件
```

- 第 3 层以下（大羽原本最深 9 层）**一律降级为标签**
- 形态词（连续/单次/循环/长尾）**不进目录名**，只做标签
- 不要"其他/通用"当垃圾桶：归不进去的先用二级分类的最接近项，再用标签区分

## 三、标签体系（照抄大羽）

每条音效 6 个标签，来自 6 个正交维度：

| 维度 | 受控取值 |
|---|---|
| 形态 | 连续 / 单次 / 循环 / 长尾 / 短尾 / 掠过 / 上升 / 下沉 / 反复 |
| 频段 | 低频 / 中频 / 高频 |
| 质感 | 电子 / 金属 / 木质 / 玻璃 / 空气 / 失真 / 合成器 |
| 强度 | 强烈 / 中等 / 柔和 / 轻微 |
| 空间 | 干声 / 混响 / 远场 / 近场 |
| 语言 | 中文 / 英语 / 男声 / 女声 / 对白（人声类专用） |

剩 2~3 个位置放**自由词**（钢琴、空灵、梦幻、悬疑），由 AI 依据描述生成。

## 四、机器可读文件

| 文件 | 用途 |
|---|---|
| `config/library-taxonomy.json` | 14 × 88 分类树（迁移脚本读它建目录） |
| `config/library-mapping.json` | 老目录 → 目标分类的映射规则（32 条，其中 3 条需人工判断） |

## 五、迁移时会用到它的地方

1. `scripts/migrate_library.py --dry-run` → 输出每个文件的"原路径 → 新路径"CSV
2. 确认后执行移动，写回滚清单
3. EchoMind 重新导入 `D:\音效库`
