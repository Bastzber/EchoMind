# 知识包（描述 + 标签 + 向量）实施记录 · 2026-10-31 凌晨

> 给明天验收用。做完的四步对应你说的 1/2/3/4。

## 一句话

新用户装完 → 点一次「导入知识包」→ 约 1~2 分钟 → 描述、标签、两套向量全部就绪，**不用再跑 2.5 小时索引**。

## 1. 导出端

`scripts/export_knowledge_pack.py`

```
输入：SQLite 的 sha256/描述/标签 + 两个 Chroma 集合
输出：EchoMind-知识包.zip
  manifest.json      版本、条数、库根目录、两个 bin 的 checksum、模型指纹
  metadata.jsonl     每行 {sha256, rel, filename, description, tags[]}
  audio_vectors.bin  定长二进制（21B 头 + 1056B/条）
  text_vectors.bin   同上
```

实测（你这台机器）：**64,893 条 → 152 MB，16 秒**。

```powershell
python scripts/export_knowledge_pack.py --out "E:\...\win-unpacked\EchoMind-知识包.zip"
```

## 2. 导入端

`backend/core/knowledge_pack.py` + 三个接口：

```
GET  /api/v1/knowledge/available   自动在安装目录向上 5 层找知识包
POST /api/v1/knowledge/import      {path?, project_id?} -> job_id
GET  /api/v1/jobs/{job_id}         进度（复用现有任务接口）
```

流程：解压 → 按 sha256 写描述/标签（分批）→ 导入两套向量（shadow 集合 + 原子切换）→ 汇总。
向量导入失败**不会**连累已写入的描述。

## 3. UI

- 设置 → 一句话描述页签：新增「知识包」卡片 + 「导入知识包」按钮（自动找包，也可手动选）
- 首次启动：库里待索引 ≥1000 且安装目录有包 → 右下角弹卡片「检测到内置知识包（64,893 条），立即导入 / 以后再说」

## 明天验收建议顺序

1. 打开软件 → 看右下角有没有「检测到内置知识包」卡片（有就点导入，观察 1~2 分钟完成）
2. 搜索几个词，确认结果带描述和标签、语义搜索有分
3. 设置 → 一句话描述 → 确认「导入知识包」按钮在、状态行会走「写描述标签 → 导入向量 → 完成」
4. 如果卡片没出现：说明你的库已经是索引好的（pending < 1000），属正常；可手动点按钮重导
