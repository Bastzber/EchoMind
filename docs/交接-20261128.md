## 踩过的坑（别再踩）

1. **批量清 import 必须先拆 `import *`**：`core/db_*.py` 的符号是星号共享的，单文件判断"未使用"全部失效。上一轮直接清，`Path` 没了、`/api/v1/files` 直接 500，已回退。正确顺序写在 `docs/代码体检-20261127.md`。
2. **顶栏是 `drag` 区**：任何新加的 div 胶囊/弹窗都要显式标 `-webkit-app-region: no-drag`，否则点不动。
3. **`renderEffectPanel` 认 `#effectPanel` 里的 `.effect-body`**：改详情页时把骨架拆了，效果器页就空白。
4. **不要用外部脚本长时间连用户库**：SQLite 被锁会让后端 `/api/v1/tags` 连报超时，看起来像代码坏了。只读查询用 `file:...?mode=ro`，且用完立刻关。
5. **中文文件名在 Node 侧 `fs` 会 ENOENT**：读写这些文件走 PowerShell；CDP 截图先落 `E:/shots`（纯英文路径）再拷进仓库。
6. **GitHub 推送偶尔抽风**（schannel handshake / connection reset）：换 `git -c http.proxy=http://127.0.0.1:7890 -c https.proxy=http://127.0.0.1:7890 push` 重试；Gitee 那个仓库要显式清空代理。
