## 二、本次新增 / 修复（r5 → r8）

### 播放器

| 功能 | 说明 |
|---|---|
| 倍速播放 | 滑条 0.25×–6.0×，步进 0.05×；**Ctrl+↑/↓ 微调**，Shift 加倍；点数字或双击方块复位 1.0×；拖动后按空格不再失效 |
| 倒放 | 生成反向临时文件播放，**进度条与播放头从右往左**，点击定位同样反向映射 |
| 多声道 | 每个声道独立波形 + Solo/Mute + 「全部可听」；>2 声道自动展开，双声道可手动开 |

### 效果器

| 功能 | 说明 |
|---|---|
| 混响预设 | 干声 / 小房间 / 大房间 / 大厅 / 教堂 / 隧道 / 户外 / 板式 |
| 湿声滑杆 | 0–100%，感知曲线；点预设即套用 |
| 导出 | 一键在原目录生成 `原名_预设.wav` |
| DSP 修复 | 卷积保留完整尾巴、能量归一化、5× 湿声增益、tanh 软限幅、缓存加版本盐 |

| 功能 | 说明 |
|---|---|

## 三、修复清单

| 问题 | 原因 | 修复 |
|---|---|---|
| 设置面板报 `loadWindowPrefs is not defined` | 函数定义在别的作用域 | 通过 `window.__loadWindowPrefs` 暴露 |
| 倒放时进度条方向错 | 进度按正向计算 | 增加 `displayProgressRatio()` 反向映射 |
| 效果器「没效果」 | 卷积尾巴被截断 + 缓存不失效 | 保留完整长度、缓存加 `CACHE_VERSION` |
| 关闭效果后仍高亮 | 只改状态未重渲染 | 开关后重新渲染面板 |
| 拖动倍速后空格失效 | 焦点留在 range 控件 | 拖动后 `blur()`，空格保护放行 range |
