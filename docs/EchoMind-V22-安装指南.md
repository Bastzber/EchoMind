# EchoMind 回声 · V22 安装与升级说明

> 适用版本：**0.3.0-beta.22（测试版 V22）** · Windows x64
> 更新日期：2026-11-25

## 一、装什么

| 文件 | 用途 | 大小 |
|---|---|---|
| `EchoMind测试版V22.zip` | **全新安装**：解压即用，不用装 Python / Node / VC++ | 约 7 GB |
| `update-beta22-r01.zip` | **增量升级**：已在用 V21 的人用这个，小得多 | 约 72 MB |

安装包和增量包都在同一个网盘目录里（链接见 `update.json` 的 url / code）。

## 二、全新安装（V22）

1. 解压 `EchoMind测试版V22.zip` 到任意目录，**路径不要带软链接/网盘同步目录**（推荐 `D:\EchoMind\`）。
2. 双击目录里的 `EchoMind.exe`。
3. 首次启动会依次做三件事：
   - 建本地数据库（`%APPDATA%\EchoMind\db\soundmind.db`）
   - 加载 CLAP / BGE 模型（顶部胶囊从「模型加载中」变成「模型就绪」）
   - 弹「导入」向导 → 选你的音效根目录开始建库
4. 想用内置 OmniVoice 做声音克隆：打开「声音克隆」→ 合成引擎保持默认「本地 OmniVoice」→ 点「下载模型」，约 3.1 GB，下一次就够，之后离线可用。

> 用户数据和程序目录分开：程序目录可以整个替换升级，`%APPDATA%\EchoMind` 里的库、标签、音色档案不会被动。

## 三、从旧版升级（增量）

1. 先**退出 EchoMind**（托盘图标也要退）。
2. 打开 EchoMind → 设置 → 检查更新，或直接拿 `update-beta22-r01.zip`。
3. 增量包会用内置公钥验签（Ed25519），签名不对会拒绝安装 —— 别去手改 zip。
4. 升级过程会自动备份被替换的文件到 `%APPDATA%\EchoMind\update-backup`，出问题可以回滚。
5. 升级完重启即可，数据库不需要迁移（V21 → V22 没有表结构变化）。

## 四、V22 装完能用的新东西（简要）

- **声音克隆不再需要 VoiceStudio**：内置 OmniVoice 引擎，克隆 + 合成都在本机完成
- 合成引擎下拉框真正生效，缺样音文稿会明确提示并能一键补上
- 克隆结果可以导出到任意目录、也能直接存进音效库
- 主界面：工具条收成「工具 ▾」抽屉（Ctrl+T）、左栏分组导航、列表加标签列、恢复一句话描述
- 窗口无边框 + 四角圆角，启动页重做

完整变更见 `CHANGELOG.md` 的 `[0.3.0-beta.22]` 段。

## 五、出问题先看这里

| 现象 | 处理 |
|---|---|
| 顶部胶囊显示「模型错误」 | 看 `%APPDATA%\EchoMind\logs\soundbot-main.log` 最后 50 行；多为模型文件缺失或被占用（关掉其它占用显存的程序再重启） |
| 声音克隆点下载没反应 | 需要能连 HuggingFace；公司网络请先开代理，或手动把权重放到 `%APPDATA%\EchoMind\models\omnivoice` |
| 搜索结果太少/太多 | 点顶部「模型就绪」胶囊，调「搜索相似度阈值」，弹窗里有当前效果说明，可「恢复默认 0.15」 |
| 列表首屏全是 00:00:00 | 这些文件元数据没读出来（损坏或格式特殊），点列表上方「批量提取元数据」 |
| 想回退到 V21 | 把备份目录里的文件拷回程序目录，或用 V21 的完整包覆盖 |

日志位置：`%APPDATA%\EchoMind\logs\`（`soundbot-main.log` 是主日志）。
