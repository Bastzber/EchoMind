# 回声 · V22-r03 更新说明

> 版本：0.3.0-beta.22（buildStamp r03）  
> 日期：2026-11-27  
> 这一轮只动界面和可用性，没有新增模型、没有改数据库结构。

## 一、设置界面

- AI 设置改成左侧导航 + 右侧内容，一屏能看全。
- 「LLM 模型」改叫 **对话模型**（副标题：帮你写描述、打标签）；「Embedding 模型」改叫 **声音理解模型**（副标题：决定按感觉搜得准不准）。不懂 AI 的词儿不用再猜。
- 一句话描述页改成任务清单：项目 / 状态 / 操作三列，缺标签时按钮才亮。
- 解释性文字统一收进「?」气泡：**鼠标移上去显示，点一下钉住**，再点或按 Esc 收起。界面上留下的只有能点的东西。

## 二、造音的两个入口改名

| 原来 | 现在 | 干什么 |
|---|---|---|
| 创造音效 | **AI 造音** | AI 现造，库里没有的声音，描述一下让 AI 生成（联网、计费） |
| 拟音工坊 | **采样拟音** | 拿你库里的采样分层拼，毫秒级、免费 |

两个窗口的标题下面都加了一句用途副标题，不再看起来像同一个功能。

**AI 造音**窗口：固定 1080×700 居中（原来铺满整个界面）；左侧子分类改成正方形图标块，每个分类一个图标；参数从滑杆改成档位按钮（距离/强度/质感/时长），右下角实时显示当前档位组合。

**采样拟音**：配方列表每个分类、每个配方都带上了自己的图标。

## 三、音效详情

拆成三页：

- **概览**：文件名、路径、时长/格式/标签数/索引状态、只读的一句话描述（右上角「去编辑 ›」跳转）、文件名重命名（两步确认，动磁盘）。
- **标签与描述**：全界面唯一能改描述和标签的地方。底部按钮显示改动数量，例如「保存改动（描述 1 · 标签 2）」；没有改动时置灰。支持「撤销改动」整页回退。
- **效果器**：混响预设、湿声强度、试听效果、导出为新文件。

保存规则：描述 + 系统标签 + 我的标签一次提交（只写数据库，失败整体回退）；文件名单独两步确认（会改磁盘）；效果器即时试听、导出另存。

## 四、列表与标签

- 标签列改成单行：显示前 3 个 + 「+N」，不再出现被切掉一半的第二行。
- 补齐缺失的系统标签：新接口只挑「有描述、没标签」的文件生成 4~8 个标签，标成 AI 标签（只参与搜索，不进左栏「我的标签」）。批量生成描述时也会顺手补。
- 「待归类审阅」现在把待归类文件直接铺进主列表（最多 1000 条），可以播、可以右键归类；原来的试听小窗保留成「试听归类」。

## 五、修复

- 调 OmniVoice 权重下载接口必抛 `NameError`（`db_manager` 未定义）。
- 顶部「模型就绪」胶囊点不开（顶栏是窗口拖动区，胶囊和阈值弹窗没标 no-drag）。顺带补上阈值弹窗里那个空白数值。
- 效果器页被改空（渲染函数只认 `#effectPanel` 里的 `.effect-body`）。
- 音频协议补上 HTTP Range 支持：点波形定位、拖进度条不再卡死或回 0，声画同步。
- 11.8 MB 的构建产物 `dist-package-app.asar` 从仓库移除；顺带清掉 2.4 KB 死 CSS 和 5 个死函数。
